時刻同期

明け (5-8時) / 昼 (8-16時) / 夕 (16-19時) / 夜 (19-5時) の4帯。境界はハード切替ではなく、空・太陽・星・配色を連続補間で滑らかに移行させる。

--

季節判定

月から春 (3-5) / 夏 (6-8) / 秋 (9-11) / 冬 (12-2) を判定。粒子系と副色・極光色が季節に従って入れ替わる。

--

描画エンジン

単一 requestAnimationFrame ループ。品質に応じてDPRと粒子数を調整。グローはスプライトキャッシュ、非表示タブでは停止する。

--

状態保存

設定は自動保存され、リロード後も復元される。自動保存を切れば手動保存モードになり、設定コピーでJSONを持ち出せる。

--

04 / Deploy

導入と運用

この端末はTermuxワンペーストで設置済み。以下のコマンドだけで起動・停止・公開更新が完結する。

Start

起動 / 再起動

ローカルとLANに固定ポートで公開。同じWi-Fiの全員がアクセスできる。

TERMUX
foxbase

ポート変更: FOXBASE_PORT=9000 foxbase

Publish

公開 固定URL

GitHub Pages に公開/更新。repo権限トークンを一度入力すれば固定URLになる。

TERMUX
foxbase-publish

出力された https://USER.github.io/REPO/ を全員に共有。

Stop

停止

サーバーだけを安全に停止。ファイルと設定は残る。

TERMUX
foxbase-stop

設置先: ~/foxbase / バージョン 1.0
